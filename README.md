# TrialScout

A small web app for finding research papers. Type a research question, get the top PubMed papers with a short plain-language summary and the full abstract on click.

Built with Flask and PubMed's free public E-utilities API. No API key and no login.

## Run it

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open http://localhost:5000.

## Record a clean demo

Save real results for the example searches once, then run in demo mode so nothing is slow or empty on camera.

```bash
python cache_demo.py             # needs internet, writes demo_cache.json
DEMO_MODE=1 python app.py        # Windows PowerShell: $env:DEMO_MODE=1; python app.py
```

Change the example searches by editing `EXAMPLES` in `cache_demo.py`.

## How it works

- `app.py` searches PubMed (`esearch`), fetches the records (`efetch`), and returns clean JSON.
- The summary is the paper's stated conclusion, or the first two sentences of the abstract. It is extracted from the abstract, not generated by an LLM.
- Your search words are highlighted in titles and summaries.

## Optional settings

| Variable | Purpose |
|---|---|
| `NCBI_EMAIL` | Your email, which NCBI asks API users to include |
| `NCBI_API_KEY` | Raises the rate limit from 3 to 10 requests per second |
| `DEMO_MODE=1` | Serve only the saved example searches |
| `PORT` | Change the port (default 5000) |

Data comes from PubMed and is for research use. Always check the original paper.
